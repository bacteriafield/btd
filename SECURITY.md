# Security Policy

Provide evidence of the bug (images, logs, errors, videos, etc.). This will help us identify the potential issue.

## Supported Versions

We only provide security updates and support for the latest released version of btd. Please ensure you are using the most up-to-date version before reporting vulnerabilities.

## Reporting a Vulnerability

If you find something wrong on project. Please, contact us at [evan.limeira@gmail.com](mailto:evan.limeira@gmail.com). We will respond as quickly as possible and coordinate a fix.
